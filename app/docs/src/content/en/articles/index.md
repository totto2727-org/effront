Use Effront to build React pages and handle user actions on the server.
Effront renders pages with React Server Components and runs user actions with Server Functions.
Use Effect services to provide the application logic that pages and Server Functions need.

## Get a page on screen {#boundaries}

[Getting started](./guide/getting-started.md) creates a homepage with a layout and a route.
Choose a [host setup](./platforms.md) to run it.

## Add data and user actions {#overview}

- [Routing](./guide/routes.md): map URLs to pages, read route parameters, and share layouts.
- [Service injection](./guide/effect.md): provide application services and use them while rendering a page.
- [Server Functions](./guide/server-functions.md): validate browser input and run server-side handlers.
