Effront uses adapters to deploy applications to different environments.
Choose an adapter for your deployment target, then set up your development and production environments.

## Choose your hosting model {#support}

| Task                                                 | Package               | Setup                                           |
| ---------------------------------------------------- | --------------------- | ----------------------------------------------- |
| Manage a Cloudflare Worker with Wrangler             | `@effront/cloudflare` | [Cloudflare Workers](./platforms/cloudflare.md) |
| Manage Cloudflare Workers and resources with Alchemy | `@effront/alchemy`    | [Alchemy](./platforms/alchemy.md)               |
| Start a Node.js or Bun HTTP server                   | `@effront/server`     | [Node.js / Bun](./platforms/node-bun.md)        |
